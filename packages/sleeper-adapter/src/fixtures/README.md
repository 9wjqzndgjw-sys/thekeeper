# Sleeper adapter fixtures

Fixtures are grouped by mapper version and replayed through `createSleeperFixtureFetch` without network access.

The `v1/documented-api-payloads.json` records are trimmed from the public response examples in the official Sleeper API documentation. Snapshots captured by an application use the same versioned shape and can be added alongside them without changing test infrastructure.

Source: `https://docs.sleeper.com/`
