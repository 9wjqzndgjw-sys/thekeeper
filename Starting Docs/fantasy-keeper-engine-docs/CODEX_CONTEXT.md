# Codex Context Index

This directory specifies a custom Sleeper-based keeper-league intelligence engine.

Start with `README.md`, then follow its reading order. The priorities are:

1. exact overall-pick keeper costs;
2. missing-pick displacement;
3. combination-level keeper optimization;
4. IV / KSV / TCV value layers;
5. pre- and post-keeper boards;
6. pre-deadline market effects;
7. resilient live Sleeper draft polling;
8. transparent explanations and replayable tests.

Do not reduce the project to a generic dynasty trade calculator.
